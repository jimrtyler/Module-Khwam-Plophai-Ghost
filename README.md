# 👻 ໂມດູນຄວາມປອດໄພ Ghost
**ເຄື່ອງມືການເສີມຄວາມແຂງແກ່ນດ້ານຄວາມປອດໄພຂອງ Windows ແລະ Azure ທີ່ໃຊ້ PowerShell**

> **ການເສີມຄວາມແຂງແກ່ນດ້ານຄວາມປອດໄພແບບເຊື່ອມໂຊມສໍາລັບ Windows endpoints ແລະສະພາບແວດລ້ອມ Azure.** Ghost ສະໜອງຟັງຊັນການເສີມຄວາມແຂງແກ່ນທີ່ອີງໃສ່ PowerShell ເຊິ່ງສາມາດຊ່ວຍຫຼຸດຜ່ອນເສັ້ນທາງການໂຈມຕີທົ່ວໄປໂດຍການປິດການໃຊ້ງານບໍລິການແລະໂພໂຕຄໍທີ່ບໍ່ຈໍາເປັນ.

## ⚠️ ຄໍາແນະນໍາທີ່ສໍາຄັນ

**ຕ້ອງການການທົດສອບ**: ທົດສອບ Ghost ໃນສະພາບແວດລ້ອມທີ່ບໍ່ແມ່ນການຜະລິດກ່ອນສະເໝີ. ການປິດບໍລິການອາດສົ່ງຜົນກະທົບຕໍ່ຟັງຊັນທຸລະກິດທີ່ຖືກຕ້ອງ.

**ບໍ່ມີການຮັບປະກັນ**: ເຖິງແມ່ນວ່າ Ghost ແນເປົ້າເສັ້ນທາງການໂຈມຕີທົ່ວໄປ, ບໍ່ມີເຄື່ອງມືຄວາມປອດໄພໃດທີ່ສາມາດປ້ອງກັນການໂຈມຕີທັງໝົດໄດ້. ນີ້ແມ່ນສ່ວນໜຶ່ງຂອງຍຸດທະສາດຄວາມປອດໄພທີ່ຄົບຖ້ວນ.

**ຜົນກະທົບດ້ານການດໍາເນີນງານ**: ຟັງຊັນບາງຢ່າງອາດມີຜົນກະທົບຕໍ່ການທໍາງານຂອງລະບົບ. ເບິ່ງຄືນການຕັ້ງຄ່າແຕ່ລະຢ່າງຢ່າງລະອຽດກ່ອນການຕິດຕັ້ງ.

**ການປະເມີນດ້ານວິຊາຊີບ**: ສໍາລັບສະພາບແວດລ້ອມການຜະລິດ, ປຶກສາກັບຜູ້ຊ່ຽວຊານດ້ານຄວາມປອດໄພເພື່ອຮັບປະກັນວ່າການຕັ້ງຄ່າສອດຄ່ອງກັບຄວາມຕ້ອງການຂອງອົງກອນຂອງທ່ານ.

## 📊 ພູມສັນຖານຄວາມປອດໄພ

ຄວາມເສຍຫາຍຈາກ Ransomware ຮອດ **57 ຕື້ໂດລາໃນປີ 2025**, ໂດຍການຄົ້ນຄວ້າຊີ້ໃຫ້ເຫັນວ່າການໂຈມຕີທີ່ປະສົບຜົນສໍາເລັດຫຼາຍຄັ້ງແມ່ນໃຊ້ປະໂຍດຈາກບໍລິການ Windows ພື້ນຖານແລະການຕັ້ງຄ່າທີ່ຜິດພາດ. ເສັ້ນທາງການໂຈມຕີທົ່ວໄປລວມມີ:

- **90% ຂອງເຫດການ ransomware** ແມ່ນກ່ຽວຂ້ອງກັບການໃຊ້ປະໂຍດຈາກ RDP
- **ຊ່ອງໂຫວ່ SMBv1** ເຮັດໃຫ້ການໂຈມຕີຄື WannaCry ແລະ NotPetya
- **Document macros** ຍັງຄົງເປັນວິທີການສົ່ງ malware ຕົ້ນຕໍ
- **ການໂຈມຕີທີ່ໃຊ້ USB** ຍັງສືບຕໍ່ແນເປົ້າເຄືອຂ່າຍທີ່ແຍກອອກຈາກອາກາດ
- **ການໃຊ້ PowerShell ໃນທາງທີ່ຜິດ** ໄດ້ເພີ່ມຂຶ້ນຢ່າງຫຼວງຫຼາຍໃນຊ່ວງຫຼາຍປີຜ່ານມາ

## 🛡️ ຟັງຊັນຄວາມປອດໄພ Ghost

Ghost ສະໜອງ **16 ຟັງຊັນການເສີມຄວາມແຂງແກ່ນ Windows** ບວກກັບ **ການປະສານງານຄວາມປອດໄພ Azure**:

### ການເສີມຄວາມແຂງແກ່ນ Windows Endpoint

| ຟັງຊັນ | ຈຸດປະສົງ | ການພິຈາລະນາ |
|----------|---------|----------------|
| `Set-RDP` | ຈັດການການເຂົ້າເຖິງ Remote Desktop | ອາດມີຜົນກະທົບຕໍ່ການບໍລິຫານທາງໄກ |
| `Set-SMBv1` | ຄວບຄຸມໂພໂຕຄໍ SMB ເກົ່າ | ຈໍາເປັນສໍາລັບລະບົບເກົ່າຫຼາຍ |
| `Set-AutoRun` | ຄວບຄຸມ AutoPlay/AutoRun | ອາດມີຜົນກະທົບຕໍ່ຄວາມສະດວກຂອງຜູ້ໃຊ້ |
| `Set-USBStorage` | ຈໍາກັດອຸປະກອນເກັບຂໍ້ມູນ USB | ອາດມີຜົນກະທົບຕໍ່ການໃຊ້ງານ USB ທີ່ຖືກຕ້ອງ |
| `Set-Macros` | ຄວບຄຸມການປະຕິບັດ macro ຂອງ Office | ອາດມີຜົນກະທົບຕໍ່ເອກະສານທີ່ມີ macro |
| `Set-PSRemoting` | ຈັດການ PowerShell remoting | ອາດມີຜົນກະທົບຕໍ່ການຈັດການທາງໄກ |
| `Set-WinRM` | ຄວບຄຸມ Windows Remote Management | ອາດມີຜົນກະທົບຕໍ່ການບໍລິຫານທາງໄກ |
| `Set-LLMNR` | ຈັດການໂພໂຕຄໍການແກ້ໄຂຊື່ | ປົກກະຕິແລ້ວປອດໄພທີ່ຈະປິດ |
| `Set-NetBIOS` | ຄວບຄຸມ NetBIOS ຜ່ານ TCP/IP | ອາດມີຜົນກະທົບຕໍ່ແອັບພລິເຄຊັນເກົ່າ |
| `Set-AdminShares` | ຈັດການ administrative shares | ອາດມີຜົນກະທົບຕໍ່ການເຂົ້າເຖິງໄຟລ໌ທາງໄກ |
| `Set-Telemetry` | ຄວບຄຸມການເກັບກໍາຂໍ້ມູນ | ອາດມີຜົນກະທົບຕໍ່ຄວາມສາມາດວິນິດໄສ |
| `Set-GuestAccount` | ຈັດການບັນຊີແຂກ | ປົກກະຕິແລ້ວປອດໄພທີ່ຈະປິດ |
| `Set-ICMP` | ຄວບຄຸມການຕອບສະໜອງ ping | ອາດມີຜົນກະທົບຕໍ່ການວິນິດໄສເຄືອຂ່າຍ |
| `Set-RemoteAssistance` | ຈັດການ Remote Assistance | ອາດມີຜົນກະທົບຕໍ່ການປະຕິບັດງານຂອງ help desk |
| `Set-NetworkDiscovery` | ຄວບຄຸມການຄົ້ນພົບເຄືອຂ່າຍ | ອາດມີຜົນກະທົບຕໍ່ການຄົ້ນຫາເຄືອຂ່າຍ |
| `Set-Firewall` | ຈັດການ Windows Firewall | ສໍາຄັນສໍາລັບຄວາມປອດໄພເຄືອຂ່າຍ |

### ຄວາມປອດໄພ Azure Cloud

## 🚀 ການເລີ່ມຕົ້ນໄວ

### ການປະເມີນຄວາມປອດໄພ
```powershell
# ໂຫລດໂມດູນ Ghost
Invoke-WebRequest 'https://raw.githubusercontent.com/jimrtyler/Ghost/main/Ghost.ps1' -OutFile .\Ghost.ps1
Get-Content .\Ghost.ps1
. .\Ghost.ps1

# ກວດສອບສະພາບຄວາມປອດໄພປັດຈຸບັນ
Get-Ghost
```

### ການເສີມຄວາມແຂງແກ່ນພື້ນຖານ (ທົດສອບກ່ອນ)
```powershell
# ການເສີມຄວາມແຂງແກ່ນທີ່ສໍາຄັນ - ທົດສອບໃນສະພາບແວດລ້ອມແລັບກ່ອນ
Set-Ghost -SMBv1 -AutoRun -Macros

# ເບິ່ງຄືນການປ່ຽນແປງ
Get-Ghost
```

### ການຕິດຕັ້ງສະຖາບັນ
```powershell
# ການຕິດຕັ້ງ Group Policy (ສະພາບແວດລ້ອມໂດເມນ)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# ການຕິດຕັ້ງ Intune (ອຸປະກອນທີ່ຈັດການດ້ວຍ cloud)
Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 🔍 ລາຍລະອຽດຟັງຊັນ

### ຟັງຊັນການເສີມຄວາມແຂງແກ່ນຫຼັກ

#### ບໍລິການເຄືອຂ່າຍ
- **RDP**: ບລັອກການເຂົ້າເຖິງ remote desktop ຫຼືສຸ່ມ port
- **SMBv1**: ປິດໂພໂຕຄໍການແບ່ງປັນໄຟລ໌ເກົ່າ
- **ICMP**: ປ້ອງກັນການຕອບສະໜອງ ping ສໍາລັບການສໍາຫຼວດ
- **LLMNR/NetBIOS**: ບລັອກໂພໂຕຄໍການແກ້ໄຂຊື່ເກົ່າ

#### ຄວາມປອດໄພແອັບພລິເຄຊັນ
- **Macros**: ປິດການປະຕິບັດ macro ໃນແອັບພລິເຄຊັນ Office
- **AutoRun**: ປ້ອງກັນການປະຕິບັດອັດຕະໂນມັດຈາກສື່ເຄື່ອນຍ້າຍ

#### ການຈັດການທາງໄກ
- **PSRemoting**: ປິດ PowerShell remote sessions
- **WinRM**: ຢຸດ Windows Remote Management
- **Remote Assistance**: ບລັອກການເຊື່ອມຕໍ່ remote assistance

#### ການຄວບຄຸມການເຂົ້າເຖິງ
- **Admin Shares**: ປິດ C$, ADMIN$ shares
- **Guest Account**: ປິດການເຂົ້າເຖິງບັນຊີແຂກ
- **USB Storage**: ຈໍາກັດການໃຊ້ອຸປະກອນ USB

### ການປະສານງານ Azure
```powershell
# ເຊື່ອມຕໍ່ກັບ Azure tenant
Connect-AzureGhost -Interactive

# ເປີດໃຊ້ງານ security defaults
Set-AzureSecurityDefaults -Enable

# ຕັ້ງຄ່າ conditional access
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# ຕະກົງຜູ້ໃຊ້ທີ່ມີສິດພິເສດ
Set-AzurePrivilegedUsers -AuditOnly
```

### ການປະສານງານ Intune (ໃໝ່ໃນ v2)
```powershell
# ເຊື່ອມຕໍ່ກັບ Intune
Connect-IntuneGhost -Interactive

# ຕິດຕັ້ງຜ່ານນະໂຍບາຍ Intune
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ ການພິຈາລະນາທີ່ສໍາຄັນ

### ຄວາມຕ້ອງການການທົດສອບ
- **ສະພາບແວດລ້ອມແລັບ**: ທົດສອບການຕັ້ງຄ່າທັງໝົດໃນສະພາບແວດລ້ອມທີ່ແຍກອອກກ່ອນ
- **ການຕິດຕັ້ງແບບຄ່ອຍເປັນຄ່ອຍໄປ**: ວິ່ງອອກມາຄ່ອຍໆເພື່ອລະບຸບັນຫາ
- **ແຜນການກັບຄືນ**: ຮັບປະກັນວ່າທ່ານສາມາດຍົກເລີກການປ່ຽນແປງໄດ້ຖ້າຈໍາເປັນ
- **ເອກະສານ**: ບັນທຶກວ່າການຕັ້ງຄ່າໃດເຮັດວຽກສໍາລັບສະພາບແວດລ້ອມຂອງທ່ານ

### ຜົນກະທົບທີ່ອາດເກີດຂຶ້ນ
- **ຄວາມຜະລິດຕະພາບຂອງຜູ້ໃຊ້**: ການຕັ້ງຄ່າບາງຢ່າງອາດມີຜົນກະທົບຕໍ່ເວິກໂຟລາຍປະຈໍາວັນ
- **ແອັບພລິເຄຊັນເກົ່າ**: ລະບົບເກົ່າອາດຕ້ອງການໂພໂຕຄໍບາງຢ່າງ
- **ການເຂົ້າເຖິງທາງໄກ**: ພິຈາລະນາຜົນກະທົບຕໍ່ການບໍລິຫານທາງໄກທີ່ຖືກຕ້ອງ
- **ຂັ້ນຕອນທຸລະກິດ**: ຢັ້ງຢືນວ່າການຕັ້ງຄ່າບໍ່ເຮັດໃຫ້ຟັງຊັນທີ່ສໍາຄັນເສຍຫາຍ

### ຂໍ້ຈໍາກັດດ້ານຄວາມປອດໄພ
- **ການປ້ອງກັນຫຼາຍຊັ້ນ**: Ghost ແມ່ນຊັ້ນຫນຶ່ງຂອງຄວາມປອດໄພ, ບໍ່ແມ່ນວິທີການແກ້ໄຂທີ່ສົມບູນ
- **ການຈັດການຢ່າງຕໍ່ເນື່ອງ**: ຄວາມປອດໄພຕ້ອງການການຕິດຕາມແລະການອັບເດດຢ່າງຕໍ່ເນື່ອງ
- **ການຝຶກອົບຮົມຜູ້ໃຊ້**: ການຄວບຄຸມທາງເຕັກນິກຕ້ອງຈັບຄູ່ກັບການຮັບຮູ້ດ້ານຄວາມປອດໄພ
- **ການພັດທະນາຂອງໄພຂົ່ມຂູ່**: ວິທີການໂຈມຕີໃໝ່ອາດຜ່ານການປົກປ້ອງປັດຈຸບັນໄດ້

## 🎯 ຕົວຢ່າງສະຖານະການການໂຈມຕີ

ເຖິງແມ່ນວ່າ Ghost ແນເປົ້າເສັ້ນທາງການໂຈມຕີທົ່ວໄປ, ການປ້ອງກັນສະເພາະຂຶ້ນກັບການປະຕິບັດແລະການທົດສອບທີ່ຖືກຕ້ອງ:

### ການໂຈມຕີແບບ WannaCry
- **ການຫຼຸດຜ່ອນ**: `Set-Ghost -SMBv1` ປິດໂພໂຕຄໍທີ່ມີຊ່ອງໂຫວ່
- **ການພິຈາລະນາ**: ຮັບປະກັນວ່າບໍ່ມີລະບົບເກົ່າທີ່ຕ້ອງການ SMBv1

### Ransomware ທີ່ໃຊ້ RDP
- **ການຫຼຸດຜ່ອນ**: `Set-Ghost -RDP` ບລັອກການເຂົ້າເຖິງ remote desktop
- **ການພິຈາລະນາ**: ອາດຕ້ອງການວິທີການເຂົ້າເຖິງທາງໄກອື່ນ

### Malware ທີ່ໃຊ້ເອກະສານ
- **ການຫຼຸດຜ່ອນ**: `Set-Ghost -Macros` ປິດການປະຕິບັດ macro
- **ການພິຈາລະນາ**: ອາດມີຜົນກະທົບຕໍ່ເອກະສານທີ່ມີ macro ທີ່ຖືກຕ້ອງ

### ໄພຂົ່ມຂູ່ທີ່ສົ່ງຜ່ານ USB
- **ການຫຼຸດຜ່ອນ**: `Set-Ghost -USBStorage -AutoRun` ຈໍາກັດການທໍາງານຂອງ USB
- **ການພິຈາລະນາ**: ອາດມີຜົນກະທົບຕໍ່ການໃຊ້ງານອຸປະກອນ USB ທີ່ຖືກຕ້ອງ

- **ຜົນກະທົບດ້ານການດໍາເນີນງານ**: ຜູ້ເຂົ້າບໍ່ຮັບຜິດຊອບຕໍ່ການຂັດຂວາງການດໍາເນີນງານ
- **ຄວາມປອດໄພທີ່ຄົບຖ້ວນ**: Ghost ແມ່ນສ່ວນປະກອບຫນຶ່ງຂອງຍຸດທະສາດຄວາມປອດໄພທີ່ສົມບູນ
